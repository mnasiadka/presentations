# Kolla & Kolla-Ansible 2026.2: What's new in Hibiscus (23.0.0)

Release summary for the Kolla User Forum. Uses the shared `openinfra` theme
(`../themes/openinfra/`).

```console
$ make html        # -> _build/revealjs/index.html
$ make serve       # build and serve on http://localhost:8000 for presenting
$ make pdf         # -> kolla-2026.2.pdf        (one page per slide)
$ make pdf-steps   # -> kolla-2026.2-steps.pdf  (one page per click)
```
